## 2. C 的任务与最小输入

对一个训练时未出现的扰动目标基因 g，用它在训练对照细胞中的表达结构预测约 2,000 个输出基因的群体平均变化：

`目标基因 g -> 对照来源的基因特征 -> Ridge/MLP -> delta_pred[g, :]`

`delta_true = 扰动细胞平均表达 - 同一划分的对照平均表达`

训练样本的单位是扰动目标。162,648 个细胞不等于同样数量的独立监督样本；B 报告每个种子只有 760 个训练目标，且模型拟合时还要去掉没有可用表示的目标。任务是 CRISPRi 群体均值响应，不能表述为完全敲除或单细胞分布生成。

每个种子需要下列输入；只交付聚合均值矩阵不足以计算对照细胞间的 PCA 和检出率：

| 文件/信息 | 用途 |
|---|---|
| `data/splits/seed_<seed>.json` | 训练/验证/测试目标，以及分别隔离的对照 ID |
| `data/processed/seed_<seed>/C_train_val.npz` | 训练与验证标签，预期分别 760、162 个目标；禁止夹带测试行 |
| `output_genes.txt`、`output_gene_mapping.csv` | 固定 2,000 个输出基因的符号、Ensembl ID 与顺序 |
| `metadata.json` | 表达层、数据版本、处理规则和限制 |
| 训练对照的细胞 × 测量基因矩阵 | 按该 seed 的训练对照 ID 导出；v1 使用全部 5,000 个测量基因，不限于输出 HVG |
| 测量基因 ID/符号对应表 | 将目标映射到输入矩阵列，记录缺失、重复和歧义 |
| 测试目标 ID | 只用于生成预测，不向模型加载测试表达或 `delta_true` |

B 的 `aggregates.npz` 和完整 h5ad 包含测试信息。若由本地重建全量 B 产物，预处理与 C 模型训练必须分开：先导出每个 seed 的训练对照和 train/val 包，再让训练入口只接收这些文件。物理持有原数据不等于严格第三方盲测；报告应准确描述实际隔离程度。

## 4. 方法与预先固定的实验设置

方法依据见 [C 方法调研](c_method_review.md)。采用仓库已有的 Ridge/MLP 主线，不扩大到基础模型预训练或复杂生成模型。

### 特征

- 每个 seed 独立拟合，只使用该 seed 的训练对照细胞。
- 对源 `X` 按基因中心化，主方案不按基因方差缩放、不做 whitening，不再追加未经核实的表达变换。
- PCA 维度上限 50。基因表示定义为 `pca.components_.T` 中对应基因的一行，即主轴系数；不是细胞的 PCA score，也不是乘过特征值平方根的另一种载荷定义。
- 保存中心、主轴、特征值、实际维度、随机种子和基因顺序。可用秩不足时记录真实维度，不补零伪装成 50 维。
- 均值使用同一批训练对照；检出率暂定义为源 `X > 0` 的细胞比例。先核查矩阵值域；若不能证明零值语义，明确标为“源矩阵正值比例”，不冒充已核实的原始 UMI 检出率。
- 比较 `pca`（最多 50 维）、`mean_detection`（2 维）、`combined`（最多 52 维）。记录零方差或低信息目标，符号覆盖不等于特征有信息。
- 特征标准化仅在有可用表示的训练目标上拟合，随后原样用于验证/测试。禁止把所有目标一起拟合标准化。
- 模型仅用有表示的训练目标拟合；缺失或歧义目标统一回退到全部训练目标的等权平均 delta。回退均值不按细胞数加权，不使用验证/测试标签。

### 模型与搜索范围

| 项目 | 预设 |
|---|---|
| 划分 | 沿用 B 的目标级 70%/15%/余数，不另抽一套有利划分 |
| 种子 | 42、123、2026，各自独立拟合、调参与保存 |
| Ridge | 多输出回归，带截距；alpha = 0.1、1、10、100 |
| MLP | 一个隐藏层，`输入 -> Linear(H) -> ReLU -> Dropout(0.1) -> Linear(G)`；H = 64、128 |
| MLP 优化 | AdamW；学习率 0.001、0.0003；weight decay 固定 0.0001；batch size 64 |
| MLP 训练 | 最多 200 epochs；patience 20；按验证目标平均 MSE 保存最佳 checkpoint |
| 输出 | 在原 delta 空间预测，不按输出基因重新标准化后偷换 MSE 的含义 |
| 基线 | 零变化、所有训练目标的等权均值；A 的 kNN/GEARS 到位后按同一数据版本接入 |
| 选择规则 | 每个 seed/表示单独选择验证 MSE 最小的参数；数值等价时优先更简单模型，Ridge 优先更强正则 |

MLP 可学习相对于训练均值的残差，再加回训练均值；这必须写入配置和运行记录。是否使用残差参数化在首次真实搜索前固定，默认使用。标准化、均值和特征拟合边界不因此改变。

预设搜索规模：3 种表示 × 3 个种子 ×（4 个 Ridge + 4 个 MLP）= 72 个候选拟合，最终保留 18 组模型/表示/种子预测，另有两类基线。冒烟测试和管线诊断另列，不当成正式重复实验。先测实际单次时间，再决定调度，不预报未经测量的训练时长。

## 5. 在运行前固定评估规则

1. 每个目标先计算指标，再对目标等权平均；不让细胞多的目标主导成绩。
2. 参数选择只看验证集目标平均 MSE。所有目标与共同的有表示子集都报告；固定回退规则下，缺失表示目标不参与模型结构优劣的误读。
3. 次要指标与仓库接口一致：delta Pearson/Spearman、Top-20 绝对变化重合率及交集内方向一致率。并列按基因 ID 字典序处理，常数向量相关记缺失并报告有效目标数。
4. 保留减去训练目标等权平均 delta 后的相关性，帮助考察超出共同响应的变化。注意 `(pred - m) - (true - m) = pred - true`，所以同时减去同一均值后的 MSE 与原 MSE 完全相同，不能另称独立的特异性证据。
5. 每个种子分别报告，再汇总均值和样本标准差。配对 bootstrap 在每个种子内按目标重采样，同一轮使用相同目标比较模型；不能把重叠种子的所有目标当作完全独立样本混在一起。
6. 预先检查输出基因中扰动目标本身的覆盖。可附加排除目标自身坐标的敏感性分析，以区分直接抑制与下游响应；它不是主调参指标，也不替换 D 约定的主结果。
7. 测试标签不参与方法选择。保存全部配置、代码状态、模型、验证成绩与输入哈希后，才生成最终测试预测；不能根据测试成绩追加参数搜索。
8. C 先完成可复算的验证评估。最终测试优先调用 D 的冻结评估实现；若尚未交付，则由单独进程运行明确标记为 C 诊断版的同定义评估，并将预测和实现交 D 独立复核，不宣称已完成 D 的验收。

零基线相关缺失、训练均值残差相关缺失、无 Top-k 交集等情形均显式记录。自定义残差相关不叫 DRF；正对照分半、DRF 或加权指标属于可选扩展，不能先看测试结果再挑最有利的评价方式。

“模型成功运行”和“模型优于基线”是两个验收问题。若 MLP 没有超过 Ridge 或训练均值，仍应交付完整结果和限制；不能为了得到正结论反复更换测试集。

- MLP 规模很小，单卡足够。若 GPU 仍繁忙，先用 CPU 跑原型和验证；不终止他人/已有任务，也不因“显存还有空余”就认定不会争用计算。
- 若以后使用服务器，GPU 任务限于物理 1、3 号，运行前重新核对索引与 UUID；设置 `CUDA_VISIBLE_DEVICES=1` 或 `CUDA_VISIBLE_DEVICES=3` 后，进程内部使用 `cuda:0`。本地授权 GPU 不受这个远端编号约束。
- 两卡可分配不同种子或参数任务，不为小型 MLP 上分布式训练。先依据试跑时间和当时占用决定串行/并行，CPU 线程数显式限制，避免多个 PCA/BLAS 进程争抢整机。
- 运行保存命令、seed、数据与代码哈希、完整配置、依赖版本、日志和退出状态；长任务采用可恢复的后台会话。启动成功不能代替完成检查。
