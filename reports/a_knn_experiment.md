# K562 k 近邻实验与独立评测

以 K562 单基因 CRISPRi 的群体平均表达变化为预测目标。按正式数据的三个划分运行余弦加权 kNN，每套使用 760 个训练目标、162 个验证目标、164 个测试目标和 2000 个输出基因。训练对照用于构建基因特征；特征缺失时使用训练扰动均值。

候选 k 为 3、5、10、20，各种子仅凭验证集 MSE 选定 k。三套均选择了 20。测试阶段沿用选定的参数。D 的独立评测入口核对 B 标签哈希、目标与输出基因顺序，逐目标计算指标与基线。调用入口在本地增加了读取 A 验证集预测的支持，指标函数沿用 D 的实现。

残差相关从预测和真值中都减去训练平均扰动后计算。对直接回退到训练均值的目标，预测残差恒为 0，D 将该相关记为缺失。每个指标的有效样本数见逐种子汇总。

## 数据版本和复现

三套划分、输出基因和训练及验证标签与 C 原版哈希一致，D 独立核验了测试标签。基因特征在本地重建，文件哈希与 C 原版不同。使用本地特征代入 C 已冻结的 Ridge 参数，复算验证预测的最大绝对差异为 4.51e-14。A 使用单独的输入清单。D 在评测时把已核实为训练均值的回退预测对齐到独立复算的均值，避免浮点舍入使理论为零的残差被计为有信号。
