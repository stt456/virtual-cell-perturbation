## 接入顺序

1. B 核实原始表达矩阵与字段；全组确认表达空间和对照规则。
2. B 发布划分、基因列表和聚合结果，记录哈希。
3. C 发布基因表示和主模型；A 后续发布 GEARS 或 kNN 参考模型。
4. A/C 交付相同接口的预测，D 独立核验顺序并评测。
5. E 按预先确定的规则选案例并分析通路，A 汇总代码与报告。

## 提交规则

- 每人使用 `a-integration`、`b-data`、`c-models`、`d-evaluation`、`e-biology` 等分支，完成后发起合并请求。
- 一次提交尽量围绕一项工作。修改接口时同步更新版本、配置与使用说明。
- 原始数据、大矩阵、模型权重与环境目录不提交；上传脚本、配置、文献笔记、小型图表和摘要结果。
- 不提交账号令牌、密码或本机绝对路径。下载数据遵守源站许可；代码许可待小组确认，暂不替他人声明许可。
- 运行结果保存随机种子、参数、环境和命令。模拟结果与真实结果目录及标记分开。
